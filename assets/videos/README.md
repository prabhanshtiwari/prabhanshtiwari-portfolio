# Project walkthrough videos

No public walkthrough video URLs were present in the verified GitHub project documentation at the time this portfolio was updated. To add a real recording:

1. Record a short screen walkthrough of the deployed project (30–90 seconds is enough).
2. Hide personal data, API keys, account tokens and private dashboards.
3. Export an MP4 (H.264) or WebM file.
4. Save it here as `<project-slug>-walkthrough.mp4`.
5. Add a `<video controls preload="metadata" poster="/assets/images/projects/<project-preview>.<svg-or-webp>">` element to that project's case-study page and reference the local video with a `<source>` element.

Do not use a video from another person's project as a substitute.
