# Project media

Each project case-study page has a large preview frame and a clickable gallery. The media controls are in the HTML and are wired by `assets/js/interactions.js`.

Replace the existing files with genuine, authorised screenshots when you have them; keep the existing filenames to avoid changing page paths. The current SVG and WebP images marked as illustrative are concept previews, not proof of deployed UI.

Job Portal also includes two additional SVG concept views for student and recruiter workflows. These are explicitly labelled illustrative, not captured screenshots.
