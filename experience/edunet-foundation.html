01 / THE EXPERIENCE

Learning how frontend work comes together

My frontend web development internship at Edunet Foundation, from August to October 2025, was an opportunity to connect the concepts I was studying with a more structured development environment. It helped me think about a user interface as a working product rather than only a visual screen.

02 / WHAT I LEARNED

Small details make the experience

The biggest lesson I carried forward was to approach frontend work systematically: understand the requirement, break the interface into manageable pieces, build with reusable structure, check behaviour at different screen sizes and refine the result. It reinforced the value of clear HTML, organised CSS and JavaScript that is understandable and maintainable.

Requirement thinkingClarifying what a screen needs to help the user do
Responsive interfacesConsidering layouts beyond a single screen size
Frontend fundamentalsConnecting structure, styling and interaction
IterationTesting the result and improving details

03 / HOW IT SHAPED MY PROCESS

Build with intention, not just speed

I became more deliberate about the steps between an idea and a finished interface: understanding the goal, choosing a simple structure, implementing one part at a time, checking edge cases and making the experience clearer. That mindset still informs how I approach personal projects.
