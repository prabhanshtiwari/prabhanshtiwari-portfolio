HOW I THINK ABOUT SOFTWARE

Use AI to build faster.
Understand what you ship.

AI can help write the code. It cannot replace understanding the system.

I use AI as part of my development workflow to explore ideas, move through repetitive work and build software. But I’m still actively exploring the principles underneath it — how the browser, APIs, databases, networks and application architecture actually work.

My goal is not just to generate something that runs. It is to understand it, question it, test it and be able to explain the decisions behind it.
